# GitHub Upload Instructions

Recommended repository name:

```text
aws-threat-detection-lab
```

## Upload through GitHub website

1. Create a new public repository named `aws-threat-detection-lab`.
2. Do not initialize with another README because this project already includes one.
3. Upload all files from this folder.
4. Commit with: `Initial commit: AWS cloud threat detection lab`.

## Upload through Git

```bash
cd aws-threat-detection-lab-github-final
git init
git add .
git commit -m "Initial commit: AWS cloud threat detection lab"
git branch -M main
git remote add origin https://github.com/Jhesse00/aws-threat-detection-lab.git
git push -u origin main
```
